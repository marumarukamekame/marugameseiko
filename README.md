# 横浜地域健康プラットフォーム Webサイト

地域健康活動を継続的に発信するための、依存パッケージを持たない静的サイト基盤です。

## ブラウザでプレビューする

Node.js 18以降がインストールされた環境で、次のコマンドを実行します。追加パッケージのインストールは不要です。

```bash
npm run dev
```

ターミナルに表示される **http://localhost:4173/** をブラウザで開いてください。

別のポートを使う場合は、次のように指定できます。

```bash
npm run dev -- --port 3000
```

Codex等のプレビュー機能からアクセスできるよう、サーバーは初期状態で `0.0.0.0` に接続します。

## コンテンツの更新

10の活動とブログ一覧のデータは `assets/js/data.js` に集約しています。
